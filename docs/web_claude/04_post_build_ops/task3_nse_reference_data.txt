  instrument_type=EQ):

    instrument_token: from Kite (instrument_token)
    lot_size:         from NSE security master (market_lot)

                      cross-check: also in fno_symbols.csv
    tick_size:        0.05 default for equity
                      (Kite also provides tick_size; use it)
    sector:           from index_members sector CSVs
                      fallback: "OTHER"
