ISSUE #25 — LiveFeedManager callback signature mismatch
  Claim: main.py wires
    live_feed.register_callback(
      lambda ticks: [candle_store.on_tick(t) for t in ticks])
  but candle_store.on_tick expects (token, ltp, ts) not a
  tick dict.

  VERIFY: Read main.py and data/candle_store.py. Confirm
  actual signatures.

  FIX: Lambda unpacks tick dict correctly:
    live_feed.register_callback(
      lambda ticks: [
        candle_store.on_tick(
          t["instrument_token"],
          t["last_price"],
          t.get("timestamp") or now_ist()
        ) for t in ticks
      ])

  CandleStore has a start() method (LF12 says clock timer
  thread).

  FIX: Add candle_store.start() in main.py Phase 0g BEFORE
  live_feed.connect(). Add candle_store.stop() in shutdown
  sequence.
