ARE THEY USEFUL?

security_master_file.csv:
  VERY USEFUL. Replaces the 5-symbol stub config/instruments.csv
  built by M38. Contains all 2802 NSE equity symbols with
  fno_stock flag + market_lot + isin.
  
  BUT — M38 schema is different:
    M38 expects: symbol, exchange, instrument_token, lot_size,
                 is_fno, tick_size, sector
    You have:    symbol, name, series, fno_stock, date_of_listing,
                 paid_up_value, market_lot, isin, face_value
  
  Missing in your file:
    - instrument_token (required by Zerodha API for WebSocket
      subscription). Must come from kite.instruments() API.
    - tick_size (standard 0.05 for most equity, some 0.01)
    - sector (NOT in NSE security master; derived from index
      membership files)
  
  Translation rules:
    your.symbol       -> m38.symbol
    your.fno_stock    -> m38.is_fno (yes/no to true/false)
    your.market_lot   -> m38.lot_size
    (always)          -> m38.tick_size = 0.05 (default for equity)
    (always)          -> m38.exchange = "NSE"
    (not present)     -> m38.instrument_token (Kite API required)

index_members.zip:
  VERY USEFUL for deriving sector information.
  Since NSE security master doesn't include sector:
    Build symbol->sector map from sector indices:
      nifty_auto -> AUTO sector
      nifty_bank -> BANKING
      nifty_it -> IT
      nifty_pharma -> PHARMA
      nifty_fin_services -> FINANCIAL_SERVICES
      nifty_fmcg -> FMCG
      nifty_healthcare -> HEALTHCARE
      nifty_metal -> METALS
      nifty_oil_gas -> OIL_GAS
      nifty_psu_bank -> PSU_BANKING
      nifty_private_bank -> PRIVATE_BANKING
      nifty_realty -> REALTY
    Symbols not in any sector index -> sector="OTHER"
  
  fno_symbols.csv: cross-check against security_master's
                   fno_stock column. Use as authority on F&O
                   eligibility (NSE adds/removes monthly).

HOW TO USE EFFECTIVELY:

Extend scripts/refresh_instruments.py (M38) to:

Step 1: Fetch Kite instrument dump for instrument_token
  kite.instruments("NSE") returns all NSE instruments with
  tokens. Filter to equity (INSTRUMENT_TYPE="EQ").

Step 2: Merge with NSE security master for lot_size and
  F&O flag:
  Join by symbol. Take lot_size from security master
  (more reliable than Kite's). Take instrument_token from
  Kite.

Step 3: Derive sector from index_members:
  Read each nifty_*.csv except fno_symbols, nifty50, nifty100,
  nifty_next50, nifty_midcap_select (these are market-cap
  indices, not sectors). Build sector lookup from the
  sector-specific indices.

Step 4: Write merged instruments.csv in M38 format.

The refresh script runs offline (operator runs morning before
market). It is the ONLY source of truth for instruments.csv.
Rebuild it weekly minimum, daily for F&O trading.
