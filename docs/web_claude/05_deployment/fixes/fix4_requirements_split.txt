================================================================
STEP 2 — CREATE requirements-dev.txt
================================================================

Create a new file for dev deps:

  cat > requirements-dev.txt << 'EOF'
# Development dependencies (tests, coverage)
# Install: pip install -r requirements-dev.txt
# Production VMs should NOT install this file.

-r requirements.txt

pytest>=9.0.0
pytest-cov>=7.0.0
EOF

The `-r requirements.txt` line means "also include everything
from requirements.txt" — so `pip install -r requirements-dev.txt`
gets both runtime + dev deps.
