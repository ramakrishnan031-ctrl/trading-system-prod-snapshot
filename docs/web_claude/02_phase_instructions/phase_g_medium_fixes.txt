MED #13 — Audit 3 #18 — CO protocol returns success=True
          even when TGT fails
  File: orders/order_protocol_co.py

  Fix: Return success=False if any leg fails.
       Add failure_details listing which leg failed.
       Caller (order_placer) already handles partial failure
       by releasing reservation; this just makes the contract
       honest.
  Test: Mock adapter with CO success + TGT failure ->
        result.success=False, failure_details names TGT.

MED #14 — Audit 3 #20 — candle_store MAX_HISTORY = 390

  File: data/candle_store.py

         is insufficient history for multi-day trail
         calculation.
  Assessment: For v2, 390 is enough (intraday focus, no
         multi-day strategies live). Smart TGT uses
         registration-time-forward candles only.
  Fix: Change MAX_HISTORY to 500 (generous buffer, still
       bounded). Add comment explaining why.
       Alternative: Make configurable via system_config.
       Recommend: bump to 500 hardcoded.
  Test: Existing tests should pass; add one verifying
        store accepts 400+ candles without eviction panic.
