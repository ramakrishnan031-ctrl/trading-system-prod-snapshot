DEFERRED TO v2.1 (rationale for each)
================================================================

All deferrals are FEATURE gaps, not SAFETY gaps. Each is
documented, not hidden.

1. Real ATR / VWAP / RSI calculation
   Why deferred: requires real-time data provider integration
   Current: FIXED_PCT fallback with WARN or HALT per config
   Risk during paper: none (foundation uses defaults)
   Risk during live: same as paper
   v2.1 scope: integrate data provider, wire real calc

2. Sector strength computation
   Why deferred: needs real market breadth data
   Current: sector from instruments.csv, strength check = 0.5
   Risk: reduces signal quality score fidelity, not safety
   v2.1 scope: add market breadth feed, compute real strength

3. Full positional strategy logic (CNC overnight)
   Why deferred: requires different EOD rules, margin model,
                 SL management across sessions
   Current: positional strategies loadable but discouraged
   Risk: do NOT trade positional strategies before v2.1
   v2.1 scope: overnight position tracking, CNC margin math,
              multi-day SL adjustment

4. Historical candle backfill on startup
   Why deferred: needs historical API wiring
   Current: live-only from connect time
   Risk: first few minutes of trading may lack context
   Mitigation: 09:20 entry window starts 5 min after market
   v2.1 scope: backfill last N hours on startup

5. Schema migration automation
   Why deferred: complex; foundation ships fresh-DB model
   Current: operator deletes DB on version bump
   Risk: historical data loss on upgrade
   v2.1 scope: proper migrations framework

6. BSE exchange support
   Why deferred: NSE-first policy
   Current: NSE-only in cost_calculator
   Risk: BSE symbols will error (feature gap, not silent bug)
   v2.1 scope: add BSE in cost calc + instruments.csv

7. Multi-account signal routing
   Why deferred: AccountRegistry built but router uses primary
   Current: single-account operation
   Risk: none for single-account use
   v2.1 scope: capital-weighted signal routing across accounts

8. Chaos test suite (Phase H)
   Why deferred: user's call to prioritize paper trial
   Current: 13 integration smoke tests cover happy paths
   Risk: unknown failure modes may surface in paper trial
   v2.1 scope: build after first paper trial week

9. Real-time charts in daily_review
   Why deferred: cosmetic
   Current: data tables only
   v2.1 scope: add matplotlib/plotly charts

10. Systemd service files / deployment automation
    Why deferred: manual invocation works for solo operator
    Current: python main.py --mode paper
    v2.1 scope: systemd unit + auto-restart

NONE of these block paper trial or live trading with intraday
equity strategies (the core v2 use case).

  - Monitor reconciliation_log in another

  - System auto-runs EOD squareoff
  - Daily review generates: reports/daily/<date>/daily_review.xlsx

    * SUMMARY sheet: total signals, P&L, funnel drop-off
    * MULTI_INNING_TRACKING: verify innings 2+3 captured
    * RECONCILIATION_LOG: should be empty or informational
    * CAPITAL_LEDGER: every movement explained
  - Review logs/*.log for any ERROR or CRITICAL entries

Shutdown (any time after 15:35):
  - Ctrl+C triggers clean shutdown
  - Verify SHUTDOWN system_event written
  - Clean logs archived
