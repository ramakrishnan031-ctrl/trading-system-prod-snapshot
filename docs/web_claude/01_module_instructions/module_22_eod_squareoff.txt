PART B — MODULE 22: orders/eod_squareoff.py
================================================================

CONTEXT: 516/516 green across 21 modules. EOD square-off is
the only module with all dependencies present and tightly
specified by P1 + P1_market_windows_api. Closes the orders
layer for safe paper-mode running.

LOCKED DECISIONS REFERENCED (from locked_decisions.yaml):
  P1                    — Times from market_windows.py only
  P1_market_windows_api — is_eod_squareoff_due() pure;
                           eod_squareoff owns "already fired" flag

ADDITIONAL DECISIONS TO LOCK (EOD1-EOD12):

EOD1 — Purpose: Square off all open intraday positions at
  EOD square-off time (15:17 IST per P1). Cancels pending
  intraday orders first, then exits filled positions with
  staggered MARKET orders. Releases capital reservations
  and used balances. Publishes PositionClosed events.

EOD2 — Constructor:
  EodSquareoff(
    adapter,             # ZerodhaAdapter
    state_store,         # for open positions + pending orders
    fund_manager,        # for release
    state_machine,       # for transitions
    bus,                 # for PositionClosed events
    market_windows,      # for is_eod_squareoff_due check
    time_authority,      # for now_ist
    kill_switch,         # to record state on EOD trigger
    logger,
    inter_order_delay_ms=500,  # P8_P13 audit fix: avoid
                                # liquidity vacuum
  )

EOD3 — "Already fired" flag (P1_market_windows_api ownership):
  Internal _fired_for_date: dict[date, bool].
  check_and_fire(now: datetime) -> bool:
    if not market_windows.is_eod_squareoff_due(now): return False
    if market_windows.is_trading_holiday(now): return False
    today = now.date()
    if _fired_for_date.get(today, False): return False
    _fire(now)
    _fired_for_date[today] = True
    return True
  Idempotent: caller can poll every second after 15:17 — only
  fires once per trading day.

EOD4 — Scheduler integration:
  Module exposes check_and_fire() but does NOT own a thread.
  main.py scheduler calls it every N seconds (configurable,
  default 5s). Keeps module testable; no embedded clock.
  Optional: provide start_polling(poll_interval_sec=5) helper
  that launches a daemon thread for environments without an
  external scheduler. Tests use check_and_fire() directly.

EOD5 — Fire sequence (lock; ordered):
  1. Log INFO: "EOD square-off triggered for {date}"
  2. Set kill_switch to SOFT_KILL with reason="EOD_SQUAREOFF"
     (prevents new entries during square-off; existing exits
     still allowed)
  3. Cancel all pending intraday entry orders:
     - Query state_store.get_pending_intraday_orders() -> list
     - For each: adapter.cancel_order(broker_order_id)
     - On success: state_machine transition to CANCELLED,
       fund_manager.release(reservation_id, "EOD_CANCEL")
     - On cancel failure: log CRITICAL, leave for reconciler
  4. Square off all open intraday positions:
     - Query state_store.get_open_intraday_positions() -> list
     - For each (in deterministic order — sorted by symbol
       per Foundation Rule 3.7):
       a. Determine exit side (BUY position -> SELL exit)
       b. adapter.place_order(symbol, exit_side, qty, MARKET,
                              INTRADAY, tag="EOD_SQUAREOFF")
       c. On success: register internal_order_id with
          state_machine, hand off to order_monitor for fill
          tracking. order_monitor will update fund_manager
          on fill (existing flow).
       d. On exception: log CRITICAL, mark position as
          EOD_EXIT_FAILED in state_store. Reconciler picks up.
       e. time.sleep(inter_order_delay_ms / 1000) BETWEEN
          orders (audit fix: prevents liquidity vacuum)
  5. Log INFO summary: positions_squared, cancels_succeeded,
     cancels_failed, exits_placed, exits_failed
  6. Publish EodSquareoffComplete event (NEW event type,
     add to core/events.py + test_events.py)
  7. Set kill_switch back to INACTIVE via resume() ONLY IF
     it was set to SOFT_KILL by THIS module (check stored flag).
     Don't auto-resume if operator had triggered hard_kill.

EOD6 — POSITIONAL positions NOT squared off:
  Filter by intent. Only INTRADAY and COVER_ORDER positions
  exit at EOD. DELIVERY (CNC) positions remain open overnight.
  Audit explicit per P1.

EOD7 — Fill confirmation OUT of scope:
  EOD module places MARKET exits and trusts order_monitor
  to track fills. Does NOT block waiting for confirmations.
  Caller (main.py) can poll order_monitor for completion
  if needed for shutdown sequencing.

EOD8 — State persistence:
  Add eod_squareoff_log table to state_store:
    id, fired_date, fired_at, positions_attempted,
    positions_succeeded, positions_failed, cancels_attempted,
    cancels_succeeded, cancels_failed, duration_sec
  One row per fire. Used by daily report.
  Bump schema_version. Update test_state_store.

EOD9 — Restart recovery:
  On construction, query eod_squareoff_log for today's date:
    if row exists with fired_at < now AND positions_failed > 0:
      log WARNING "EOD ran today but had failures; reconciler
                   should handle"
  Do NOT auto-fire on restart even if past 15:17. Operator
  must manually invoke if needed.
  Edge case: if restart at 15:18 and EOD never ran today,
  log CRITICAL and DO fire (one-time recovery, mark log row).
  Lock: recovery-fire allowed only if no log row exists for
  today AND now is past EOD time AND not past 15:30 (market
  close).

EOD10 — Emergency manual fire:
  fire_now(reason: str, triggered_by: str) -> EodFireResult
  Bypasses time check. Used by operator emergency shutdown.
  Logs CRITICAL with reason. Marks _fired_for_date[today].
  Does NOT skip the kill_switch SOFT_KILL step.

EOD11 — Layer & deps:
  Layer 5 (orders/). Imports: stdlib (threading, time, datetime),
  core.exceptions, core.events, core.logger, core.time_authority,
  core.state_store, core.market_windows,
  broker.zerodha_adapter, broker.order_state_machine,
  capital.fund_manager, capital.kill_switch.

EOD12 — System config additions:
  eod_squareoff:
    inter_order_delay_ms: int   (default 500, validated >= 0, <= 5000)
    poll_interval_sec: int      (default 5, validated >= 1)
    auto_resume_kill_switch: bool (default true)
  Update YAML stub. Re-run test_config_loader.
