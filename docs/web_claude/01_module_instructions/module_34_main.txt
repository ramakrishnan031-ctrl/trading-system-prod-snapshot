MAIN3 — Top-level error handling (E1):
  if __name__ == "__main__":
    try:
        sys.exit(main())
    except TradingSystemError as e:
        logger.critical("system_error", exc_info=True)
        sys.exit(1)
    except Exception as e:
        logger.critical("unexpected_error", exc_info=True)
        sys.exit(2)

  Exit codes:
    0 — clean shutdown
    1 — TradingSystemError
    2 — unexpected exception
    3 — startup check failure (blocking)
    4 — HALT scenario without --resume
    5 — invalid args / config

MAIN15 — Shutdown sequence (MAIN13 triggered):
  Clean shutdown order (reverse of start):
  1. Log INFO "shutdown initiated"
  2. signal_processor.stop()     # stop accepting new work

     (Flask dev server doesn't support clean stop —
     acceptable for v2; daemon thread dies on process exit)
  5. smart_tgt.stop()
  6. order_reconciler.stop()
  7. order_monitor.stop()
  8. live_feed.disconnect()
  9. notifier.send(INFO, "System stopping", ...)

        event_type="SHUTDOWN",
        event_ts=now_ist_iso(), ...

  12. Log INFO "shutdown complete"
  13. return 0

MAIN18 — Callback implementations:

  _on_critical_failure_cb(source: str, reason: str):
    Log CRITICAL.
    kill_switch.soft_kill(reason=f"{source}: {reason}",
                          triggered_by="auto")
    notifier.send(CRITICAL, ...)

  _on_orphan_cb(order_id: str, reason: str):
    Same path — CRITICAL alert + kill_switch.soft_kill.

  _on_gate_release_cb(entry: WatchEntry, reason: str):
    If reason == "PRICE_HIT":
      Reconstruct signal flow: call signal_processor's
      post-screen pipeline with the entry data.
      Ideally signal_processor exposes a public method
      continue_from_gate(entry) — if not, main.py wires
      directly to sizer + risk + reserve + placer here.
      Lock: extend signal_processor with this method.
    If reason in ("TIMEOUT", "QUOTE_UNAVAILABLE"):
      Log INFO, no action (signal status already updated
      by entry_gate).
