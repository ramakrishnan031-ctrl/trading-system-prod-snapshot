SU10 — Interactive Step 3b: Login flow

  Port from old system auth/zerodha_login.py:

  a. Resolve credentials from .env:
       api_key = os.environ.get(acct.api_key_env)
       api_secret = os.environ.get(acct.api_secret_env)
     If missing: print error with env var name, exit 5.

  b. Build login URL:
       https://kite.zerodha.com/connect/login?v=3&api_key={api_key}

  c. Open in default browser:
       webbrowser.open(login_url)

  d. Print instructions:
       "  Browser opened. Complete login:"
       "    User ID + Password + TOTP from Kite app"
       ""
       "  After login, browser redirects to localhost URL."
       "  Copy the request_token value from the URL."
       ""
       "  Paste request_token here: "

  e. Exchange request_token -> access_token:
       checksum = sha256(api_key + request_token + api_secret)
       POST https://api.kite.trade/session/token
       Parse response for access_token.
       On error: print, exit 1.

  f. Save token:
       data_store/session/zerodha_token.json:
       {
         "account_id": "LFL836",
         "broker": "zerodha",
         "access_token": "<token>",
         "api_key": "<for mismatch detect>",
         "date": "2026-04-17",
         "saved_at": "2026-04-17T08:45:12+05:30",
         "expires_at": "2026-04-18T05:00:00+05:30"
       }

  g. Print success:
       "Login successful! Token saved for LFL836."
