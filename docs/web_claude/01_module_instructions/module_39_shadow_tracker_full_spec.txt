PURPOSE — Concern 4 fix:
  Original trade places real broker order and exits at SL or TGT.
  shadow_tracker then SIMULATES innings 2 and 3 (up to 3 total)
  by continuing to watch the same symbol. Each simulated inning:
    - entry_price = previous inning's exit_price
    - sl_price, tgt_price recomputed using original strategy
      rules applied to new entry_price
    - No real broker order
  Prevents the old-system bug: "system reports TGT hit when
  actually SL hit then price recovered and hit TGT later".
  User wants visibility into all 3 innings for the day.

SH3 — Event subscription (on construction):
  bus.subscribe(PositionClosed, self._on_position_closed)

  Handler receives PositionClosed with payload:
    {trade_id, symbol, exit_price, realized_pnl, signal_id}
  Logic:
    1. Look up trade details from state_store:
         direction, strategy_name (via signal_id -> scanner -> scan_map)
    2. Look up original strategy params (sl_method/pct, tgt_method/pct)
    3. Derive inning 1 data:
         entry_price = trade.entry_price (actual filled)
         sl_price = trade.sl_price
         tgt_price = trade.tgt_price
         exit_price = event.exit_price
         exit_reason = derived from trade.close_reason
                       (SL_HIT -> "SL", TGT_HIT -> "TGT", EOD -> "EOD")
         is_real = True
    4. Persist inning 1 to innings table
    5. If alert_per_inning: send telegram INFO
    6. If exit_reason in ("SL", "TGT") AND inning_number < max_innings
       AND market_windows.is_market_open(now):
         _start_simulated_inning(prev_inning=inning_1)

SH4 — Starting a simulated inning:
  _start_simulated_inning(prev_inning: Inning):
    1. entry_price = prev_inning.exit_price
    2. entry_ts = prev_inning.exit_ts (or now_ist if missing)
    3. direction = prev_inning.direction
    4. Fetch original strategy for this symbol (via trade.signal_id)
    5. Apply strategy.sl_method to new entry_price -> new sl_price
       Apply strategy.tgt_method to new entry_price -> new tgt_price
       (Same derivation rules as signal_processor._derive_prices
        and _derive_target, already implemented.)
    6. Create Inning dataclass:
         inning_number = prev_inning.inning_number + 1
         trade_id = prev_inning.trade_id
         symbol, direction copied
         entry_price, entry_ts as above
         sl_price, tgt_price as computed
         exit_price=None, exit_ts=None, exit_reason=None
         is_real=False
    7. Persist to innings table
    8. Register in _active_innings dict under RLock
    9. Log INFO: "Started inning {N} for {symbol} entry={price}"

SH5 — Tick processing:
  on_tick(tick: dict):
    Expects tick with keys: instrument_token, last_price.
    (Consistent with BLOCKER #1 callback fix.)

    Resolve symbol from token:
      row = instrument_cache.get_by_token(tick["instrument_token"])
      symbol = row.symbol
    (Module 38 provides instrument_cache; inject via constructor)

    Under lock:
      matching = [inning for inning in _active_innings.values()
                  if inning.symbol == symbol]
    For each match:
      ltp = tick["last_price"]
      hit = _check_hit(inning, ltp)
      if hit:
        _close_inning(inning, ltp, exit_reason=hit)

SH6 — Hit detection:
  _check_hit(inning, ltp) -> Optional[str]:
    if inning.direction == "LONG":
      if ltp <= inning.sl_price: return "SL"
      if ltp >= inning.tgt_price: return "TGT"
    else:  # SHORT
      if ltp >= inning.sl_price: return "SL"
      if ltp <= inning.tgt_price: return "TGT"
    return None

SH7 — Closing an inning:
  _close_inning(inning, exit_price, exit_reason):
    Under RLock:
      1. Compute pnl:
           if direction == "LONG":
             pnl_per_share = exit_price - entry_price
           else:
             pnl_per_share = entry_price - exit_price
           pnl_pct = (pnl_per_share / entry_price) * 100
           duration_sec = (now - entry_ts).total_seconds()
      2. Update innings table via update_inning_close(...)
      3. Remove from _active_innings
    If alert_per_inning:
      notifier.send(INFO with inning summary)
    Decision for next inning:
      If exit_reason in ("SL", "TGT")
         AND inning.inning_number < max_innings
         AND market_windows.is_market_open(now):
        _start_simulated_inning(inning)  # cascade
      Else: end of chain for this trade

SH8 — EOD handling:
  Subscribe to EodSquareoffComplete event (add to core/events.py
  if not already present).
  On EOD:
    Under lock:
      active_copy = list(_active_innings.values())
    For each inning in active_copy:
      Determine current_ltp:
        if live_feed has last tick for symbol: use it
        else: use inning.entry_price (fallback, log WARNING)
      _close_inning(inning, current_ltp, exit_reason="EOD")
    No new innings started after EOD.

    entry_price REAL NOT NULL,

SH10 — state_store helpers (4 new):

  insert_inning(inning: Inning) -> None
    Inserts all fields. is_real stored as 0/1.
    Raises IntegrityError on UNIQUE violation (should not
    happen in normal flow).

  update_inning_close(trade_id, inning_number, exit_price,
                      exit_ts, exit_reason, duration_sec,
                      pnl_pct, pnl_per_share) -> None
    UPDATE innings WHERE trade_id=? AND inning_number=?

  get_innings_for_trade(trade_id) -> list[Inning]
    Returns all innings for a trade, ordered by inning_number.

  get_innings_for_date(date_iso) -> list[Inning]
    Returns all innings where entry_ts starts with date_iso.
    Ordered by (trade_id, inning_number).

SH14 — Thread safety:
  _active_innings dict guarded by threading.RLock.
  tick callback fires on live_feed consumer thread.
  PositionClosed handler fires on event bus thread.
  EOD handler fires on event bus thread.
  All acquire same RLock.
  No nested calls that re-enter lock from different owner.

SH15 — Testing (tests/unit/test_shadow_tracker.py):

  EVENT HANDLING:
  - PositionClosed event -> inning 1 persisted with is_real=True
  - PositionClosed for closed trade with no strategy found ->
    logs ERROR, no inning created
  - PositionClosed when enabled=False -> no-op

  CASCADE:
  - Inning 1 exit_reason=TGT -> inning 2 auto-started
  - Inning 2 exit_reason=SL -> inning 3 auto-started
  - Inning 3 completes -> no inning 4 (max_innings=3)
  - Inning 1 exit_reason=EOD -> NO inning 2 (chain ends)
  - Inning 2 exit_reason=EOD -> inning 3 NOT started

  HIT DETECTION:
  - LONG: SL hit when ltp <= sl_price
  - LONG: TGT hit when ltp >= tgt_price
  - LONG: ltp between SL and TGT -> no hit
  - SHORT: SL hit when ltp >= sl_price
  - SHORT: TGT hit when ltp <= tgt_price
  - SHORT: ltp between SL and TGT -> no hit
  - Boundary: ltp == sl_price -> SL hit
  - Boundary: ltp == tgt_price -> TGT hit

  SIMULATED INNING CALCULATION:
  - LONG strategy FIXED_PCT: inning 2 sl/tgt correctly
    computed from inning 1 exit_price
  - SHORT strategy FIXED_PCT: same
  - RISK_REWARD target method applied to new entry

  PERSISTENCE:
  - insert_inning stores all fields correctly
  - update_inning_close populates closure fields
  - get_innings_for_trade returns correct order
  - get_innings_for_date filters by date correctly

  PNL:
  - LONG profit case: pnl_per_share + pnl_pct correct
  - LONG loss case: pnl_per_share + pnl_pct negative
  - SHORT profit: exit < entry -> positive pnl
  - SHORT loss: exit > entry -> negative pnl

  EOD:
  - EodSquareoffComplete -> active innings closed with
    exit_reason=EOD
  - No innings started after EOD even if hit detected later

  ALERTS:
  - alert_per_inning=True -> notifier.send called on each close
  - alert_per_inning=False -> no notifier calls
  - Alert contains symbol, inning_number, entry, exit, pnl_pct

  TOKEN MAPPING:
  - on_tick uses instrument_cache to resolve symbol
  - Unknown token in tick -> log WARNING, skip

  THREAD SAFETY:
  - Concurrent PositionClosed + on_tick for same symbol:
    no races, consistent state
  - Concurrent on_tick from two threads for different symbols:
    both processed correctly

  IS_REAL FLAG:
  - Inning 1: is_real=True
  - Inning 2: is_real=False
  - Inning 3: is_real=False

  Expected test count: 30-35
