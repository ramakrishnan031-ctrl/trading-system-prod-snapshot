SP4 — Lifecycle:
  start() launches dispatcher thread + N executor workers.
  stop() signals shutdown, drains in-flight tasks (5s timeout),
         shuts down executor cleanly.
  is_running() -> bool

SP5 — Dispatcher loop:
  Single dispatcher thread runs:
    while not _stop:
      try:
        signal_tuple = signal_queue.get(timeout=drain_poll_sec)
        executor.submit(_process_one, signal_tuple)
      except queue.Empty:
        continue
  Dispatcher NEVER processes signals itself. Pure handoff.

SP6 — Pipeline (lock; ordered, short-circuit on first reject):
  _process_one(signal_id, scanner_name, symbol, trigger_price,
               triggered_at) execution:

  1. Pre-flight checks (cheap, no I/O):
     - kill_switch.is_active("entry") -> reject "KILL_SWITCH"
     - market_windows.is_entry_allowed(now_ist) -> reject
       "OUTSIDE_ENTRY_WINDOW"
     - signal age > expiry -> reject "EXPIRED"
       (defense-in-depth; receiver also checks)

  2. Strategy lookup:
     - scan_webhook_map.get(scanner_name) -> intent + side +
       strategy params. Reject "UNKNOWN_SCANNER" if missing.

  3. Quality scoring (optional in this build):
     - if quality_scorer is None: assign tier="MEDIUM"
     - else: score = quality_scorer.score(symbol, ...)
             tier from score thresholds in scoring_weights.yaml
     - reject "BELOW_SCORE_THRESHOLD" if score < min_pass

  4. Secondary screening (optional in this build):
     - if secondary_screener is None: skip
     - else: result = secondary_screener.screen(signal_payload)
             reject with screener-provided reason if not passed

  5. Position sizing:
     - sizer.calculate(symbol, side, entry_price, sl_price,
                       intent, score_tier, lot_size)
     - reject if sizing.success=False (use sizing.reason)

  6. Risk approval:
     - risk_engine.approve(symbol, side, intent, sizing,
                           signal_id)
     - reject with approval.failed_check if not approved

  7. Capital reservation:
     - fund_manager.reserve(symbol, qty, price, intent,
                            signal_id)
     - reject "RESERVE_FAILED" if not success
       (race condition: someone else used capital between
        approve and reserve)

  8. Order placement (optional in this build):
     - if order_placer is None: log INFO, mark signal
       PROCESSED_NO_PLACER, release reservation, return
     - else: order_placer.place(symbol, side, qty, entry_price,
                                sl_price, intent, signal_id,
                                reservation_id)
     - On placement exception: release reservation, mark
       signal PLACEMENT_FAILED, log ERROR

  9. Update signal status: PROCESSED with placed_at_ts.

SP7 — Audit Issue #21 fix — _in_flight cleanup ALWAYS:
  Receiver added symbol to _in_flight on accept. Processor
  must remove it after pipeline finishes (success or fail).
  Use try/finally:
    try:
      _process_one(...)
    finally:
      receiver.release_in_flight(symbol)
  Audit flaw: receiver added but processor exception path
  forgot to clear -> permanent block on that symbol.

SP8 — Audit Issue #20 fix — derive sl_price:

                   (atr from candle data — for now, if no
                    atr provider, log WARNING and use fixed_pct
                    fallback configured in YAML)
  For now: implement fixed_pct only. atr method = TODO with

SP9 — Signal status updates (write to state_store on EVERY
  state change):
  QUEUED        -> set by receiver
  PROCESSING    -> set when _process_one starts
  REJECTED_<X>  -> set on any pipeline reject (X = check name)
  RESERVED      -> set after step 7 success
  PROCESSED     -> set after step 9 (full pipeline success)
  PLACEMENT_FAILED -> set on step 8 exception
  Each update: state_store.update_signal_status(signal_id,
    status, reason, ts).
  Audit P16: every signal_id has final status + ts + reason.

SP10 — Strategy params source:
  scan_webhook_map: dict[scanner_name, scanner_config] where
  scanner_config: {intent, side, strategy_yaml_path}.
  strategy_yaml loaded ONCE at processor construction (don't
  re-read per signal). Hold dict[scanner_name, strategy_dict]
  in memory.
  If a strategy YAML missing or invalid: refuse to start
  (per Project Rule 14 — Schema Enforcement). Already
  validated by config_loader at startup.

SP11 — Concurrency safety:
  - signal_queue is thread-safe (queue.Queue)
  - state_store calls thread-safe (SQLite WAL)
  - fund_manager calls thread-safe (own RLock)
  - risk_engine is stateless
  - position_sizer is stateless
  Therefore _process_one is naturally thread-safe across
  workers. No additional locks in processor.

SP12 — Error handling:
  - Pipeline rejection: logged INFO, signal status updated,
    NOT raised
  - Unexpected exception in _process_one: logged ERROR with
    full traceback, signal status PLACEMENT_FAILED, in_flight
    released, NOT raised (worker thread continues)
  - kill_switch tripped DURING processing: detected at next
    pre-flight on next signal; current signal completes
  - record_api_failure called on any BrokerError caught
    (kill_switch auto-trip mechanism)
