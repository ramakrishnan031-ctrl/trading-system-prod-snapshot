S3 — StrategyConfig Pydantic model (COMPLETE field list):

  # --- Identity ---
  name: str                    # e.g. "open_low_breakout_long"
  display_name: str            # e.g. "Open Low Breakout Long"
  description: str             # one-liner purpose

  # --- Direction & Product ---
  direction: str               # "LONG" | "SHORT"
  intent: str                  # "INTRADAY" | "DELIVERY"
  order_protocol: str          # "CO_PLUS_TGT" | "LIMIT_TRIPLE"

  # --- Entry ---
  entry_method: str            # "MARKET" | "LIMIT"
  entry_offset_pct: float      # for LIMIT: offset from trigger price
                                # BUY: trigger * (1 - offset) = limit
                                # SELL: trigger * (1 + offset) = limit
                                # default 0.0 (at trigger price)

  # --- Stop Loss ---
  sl_method: str               # "FIXED_PCT" | "ATR"
  sl_pct: float                # used when sl_method=FIXED_PCT
                                # LONG: sl = entry * (1 - sl_pct)
                                # SHORT: sl = entry * (1 + sl_pct)
  sl_atr_multiplier: float     # used when sl_method=ATR
                                # sl = entry -/+ atr * multiplier
                                # default 1.5
  sl_min_pct: float            # floor: SL distance never < this %
                                # default 0.003 (0.3%)
  sl_max_pct: float            # cap: SL distance never > this %
                                # default 0.05 (5%)

  # --- Target ---
  tgt_method: str              # "FIXED_PCT" | "RISK_REWARD" | "ATR"
  tgt_pct: float               # used when tgt_method=FIXED_PCT
  tgt_risk_reward: float       # used when tgt_method=RISK_REWARD
                                # tgt_distance = sl_distance * ratio
                                # default 2.0
  tgt_atr_multiplier: float    # used when tgt_method=ATR
                                # default 2.5

  # --- Smart TGT (trail SL) ---
  smart_tgt_enabled: bool      # enable trail SL via smart_tgt_manager
  smart_tgt_trail_trigger_pct: float  # start trailing after this %
                                       # profit reached (default 0.005)
  smart_tgt_trail_step_pct: float     # trail SL by this step
                                       # (default 0.003)

  # --- Pullback Wait (P11a) ---
  pullback_wait_enabled: bool          # opt-in to entry_gate delay
  pullback_wait_tolerance_pct: float   # price must retrace this %
                                        # default 0.005
  pullback_wait_timeout_sec: int       # hard timeout (default 180)

  # --- Screening Thresholds ---
  min_score: int               # minimum quality score to pass
                                # default: use global from scoring_weights
                                # if set here, overrides global
  min_volume_surge: float      # step 1 threshold (default 1.3)
  min_adr_pct: float           # ATR/ADR filter (default 0.5%)
  max_spread_pct: float        # bid-ask spread cap (default 0.5%)

  # --- Risk ---
  max_risk_pct: float          # per-trade risk override
                                # default: use global from system_config
                                # if set, overrides position_sizer default
  lot_size: int                # for F&O; equity = 1 (default 1)

  # --- Time ---
  entry_start_time: str        # override entry window start
                                # format "HH:MM", default "09:30"
  entry_end_time: str          # override entry window end
                                # default "13:30"
  active_days: list[str]       # ["MON","TUE","WED","THU","FRI"]
                                # default: all 5 weekdays

S4 — Validation rules (Pydantic validators):
  - direction IN ("LONG", "SHORT")
  - intent IN ("INTRADAY", "DELIVERY")
  - order_protocol IN ("CO_PLUS_TGT", "LIMIT_TRIPLE")
  - entry_method IN ("MARKET", "LIMIT")
  - sl_method IN ("FIXED_PCT", "ATR")
  - tgt_method IN ("FIXED_PCT", "RISK_REWARD", "ATR")
  - sl_pct > 0 when sl_method=FIXED_PCT
  - sl_min_pct <= sl_pct <= sl_max_pct when FIXED_PCT
  - tgt_pct > 0 when tgt_method=FIXED_PCT
  - tgt_risk_reward > 0 when tgt_method=RISK_REWARD
  - entry_start_time < entry_end_time (parse as time objects)
  - active_days subset of {MON,TUE,WED,THU,FRI}
  - lot_size >= 1
  - All float fields that are percentages: > 0, < 1
    (expressed as decimal: 0.01 = 1%, not 1.0 = 1%)
  - extra="forbid" (no unknown fields — Project Rule 14)

S8 — strategies/schema.py exports:
  StrategyConfig — the Pydantic model
  validate_strategy(yaml_path: Path) -> StrategyConfig
    Loads YAML, validates, returns typed object.
    Raises ConfigSchemaError on failure.

S9 — strategies/loader.py exports:
  load_all_strategies(strategies_dir: Path) -> dict[str, StrategyConfig]
    Loads ALL .yaml files from dir.
    Returns dict keyed by strategy name.
    ANY invalid file -> raise ConfigSchemaError immediately
    (Project Rule 14: no partial loads).
  get_strategy(name: str) -> StrategyConfig
    Lookup from loaded dict. Raises ConfigMissingError if
    not found.
  Strategies loaded ONCE at startup (no hot reload).
