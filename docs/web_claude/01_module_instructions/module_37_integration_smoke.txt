IT5 — Required scenarios (lock; all 7 must pass):

  SCENARIO 1 — Happy path (signal -> placed -> filled -> closed):
    - Seed SimKiteClient: quote=100, margins.available=100000
    - Start main.py in background thread (or directly wire
      subsystems if full main.py too heavy)
    - POST /webhook/open_low_breakout_long with one signal
      for RELIANCE at trigger_price=100
    - Wait for signal to flow through:
      * webhook accepts (200)
      * signal queued
      * signal_processor picks up
      * screener PASSES (pre-seed market_data)
      * sizer computes qty
      * risk_engine approves
      * fund_manager reserves capital
      * order_placer places CO + TGT
      * order_monitor tracks
      * SimKite scripted to return COMPLETE status on next poll
      * OrderFilled event published
      * fund_manager commits reservation to used
    - Verify state_store:
      * signals row with status=PROCESSED
      * orders rows (CO + TGT) with status=COMPLETE/SUBMITTED
      * capital_ledger rows (reserve, commit)
      * reconciliation_log empty (nothing to reconcile)

  SCENARIO 2 — Screener rejection:
    - Same setup, but mock market_data to fail step_2
      (ltp < vwap for LONG)
    - Signal should be rejected at screener
    - Verify: signals.status = REJECTED_vwap_position
    - Verify: no orders placed, no capital reserved

  SCENARIO 3 — Risk engine rejection (max_open_positions):
    - Pre-seed state_store with N open positions at cap
    - Signal should pass screener but fail risk
    - Verify: signals.status = REJECTED_OPEN_POSITIONS
    - Verify: no capital reserved

  SCENARIO 4 — Duplicate signal (dedup):
    - POST same signal fingerprint twice within same minute
    - First: 200 accepted
    - Second: 200 with DUPLICATE in response

  SCENARIO 5 — Kill switch blocks new signals:
    - kill_switch.soft_kill(reason="test")
    - POST new signal
    - Verify: 403 response
    - Verify: signals.status includes KILL_SWITCH rejection

  SCENARIO 6 — EOD square-off:
    - Pre-seed with 2 open intraday positions
    - Advance mocked time to 15:17
    - Trigger eod.check_and_fire()
    - Verify: adapter.place_order called with opposite side
      for each position (MARKET exit)
    - Verify: eod_squareoff_log row written
    - Verify: kill_switch set to SOFT_KILL during EOD,
      resumed after

  SCENARIO 7 — Reconciler detects manual close:
    - Pre-seed state_store with 1 open trade for RELIANCE
    - Script SimKiteClient.positions() to return empty list
      (broker says no position)
    - Trigger reconciler._reconcile()
    - Verify: trade marked CLOSED_MANUAL
    - Verify: fund_manager.release_used called
    - Verify: reconciliation_log row with MANUAL_CLOSE
