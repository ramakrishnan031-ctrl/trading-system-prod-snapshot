SPW4 — Entry/SL price derivation (moved here from planning):
  _derive_prices(trigger_price, strategy) -> tuple[float, float]:
    entry_price = trigger_price  (default)
    If strategy.entry_method == "LIMIT":
      if direction=LONG:  entry = trigger * (1 - entry_offset_pct)
      if direction=SHORT: entry = trigger * (1 + entry_offset_pct)

    If strategy.sl_method == "FIXED_PCT":
      if direction=LONG:  sl = entry * (1 - sl_pct)
      if direction=SHORT: sl = entry * (1 + sl_pct)
    If strategy.sl_method == "ATR":
      For v2: fall back to sl_pct with WARNING (ATR data
      not yet available). v2.1 adds real ATR.

    Enforce sl_min_pct / sl_max_pct bounds:
      sl_distance = abs(entry - sl)
      sl_distance_pct = sl_distance / entry
      if sl_distance_pct < sl_min_pct: adjust sl to min
      if sl_distance_pct > sl_max_pct: adjust sl to max
      Log WARNING on adjustment.

    Return (entry_price, sl_price)

SPW5 — Target price derivation:
  _derive_target(entry, sl, strategy) -> float:
    If tgt_method == "FIXED_PCT":
      if direction=LONG:  tgt = entry * (1 + tgt_pct)
      if direction=SHORT: tgt = entry * (1 - tgt_pct)
    If tgt_method == "RISK_REWARD":
      sl_distance = abs(entry - sl)
      if direction=LONG:  tgt = entry + sl_distance * ratio
      if direction=SHORT: tgt = entry - sl_distance * ratio
    If tgt_method == "ATR":
      Same fallback as SL (use FIXED_PCT for now).
    Return tgt_price.

  Note: target is computed here but used by order_placer
  when placing TGT leg (CO_PLUS_TGT protocol).
