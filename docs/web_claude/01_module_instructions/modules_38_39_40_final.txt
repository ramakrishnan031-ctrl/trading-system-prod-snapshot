IC1 — Two new config files:

IC3 — InstrumentCache class:
  InstrumentCache(
    instruments_csv_path: Path,
    logger,
  )
  Loads CSV at construction. Builds two lookup dicts:
    by_symbol: {symbol -> InstrumentRow}
    by_token: {instrument_token -> InstrumentRow}

  InstrumentRow (frozen dataclass):
    symbol, exchange, instrument_token, lot_size,
    is_fno, tick_size

  API:
    get_by_symbol(symbol) -> InstrumentRow
      Raises InstrumentNotFoundError if missing.
    get_by_token(token) -> InstrumentRow
      Raises InstrumentNotFoundError if missing.
    lot_size(symbol) -> int
    is_fno(symbol) -> bool
    tick_size(symbol) -> float
    round_price(symbol, price) -> float
      Rounds to nearest tick_size. Used by order_placer
      for LIMIT prices.

IC4 — New exception:
  InstrumentNotFoundError(ConfigError, SEVERITY="ERROR")
  Add to core/exceptions.py.

IC5 — AccountRegistry class:
  AccountRegistry(
    accounts_csv_path: Path,
    logger,
  )
  Loads CSV. Validates:
    - At least 1 enabled account
    - Sum of enabled capital_share_pct == 1.0 (tolerance 0.01)
    - All referenced env vars must be set (log warning if
      not set; don't raise — paper mode may not need real tokens)

  AccountRow (frozen dataclass):
    account_id, broker, api_key, access_token,
    capital_share_pct, enabled
    (api_key and access_token resolved from env at load time)

  API:
    get_enabled_accounts() -> list[AccountRow]
    get_primary_account() -> AccountRow
      First enabled account. Used in single-account mode.
    get_account(account_id) -> AccountRow

IC7 — position_sizer update:
  PS signature currently takes lot_size as parameter
  (from strategy.lot_size).
  NEW: signal_processor calls
    real_lot = instrument_cache.lot_size(symbol)
    if strategy.lot_size > 1 and real_lot != strategy.lot_size:
      log WARNING (strategy override mismatched)
    Use real_lot for actual sizing.
  For equity: instrument_cache returns 1, matches default.
  For F&O: uses actual lot, strategy.lot_size can set a
  multiplier (e.g., trade 2 lots -> strategy.lot_size=2*real_lot).

  CORRECTION: Keep strategy.lot_size meaning "number of lots
  to trade" (default 1). Final qty = strategy.lot_size *
  instrument_cache.lot_size(symbol) * sizer's calculated units.
  This makes equity (instrument lot_size=1) and F&O
  (instrument lot_size=50) work uniformly.

SH1 — Inning dataclass:
  Inning (frozen):

SH2 — Constructor:
  ShadowTracker(
    state_store,
    bus,                    # subscribe to PositionClosed
    live_feed,              # subscribe to tick updates
    market_windows,
    time_authority,
    notifier,               # telegram alerts per inning
    logger,

    alert_per_inning=True,

SH3 — Event subscription:
  On construction, bus.subscribe(PositionClosed,
                                  self._on_position_closed)
  Handler receives PositionClosed event:
    payload has {trade_id, symbol, exit_price, realized_pnl,
                  signal_id}
    Look up trade details from state_store (direction,
    sl_pct, tgt_pct from original signal's strategy).
    Persist inning 1 to innings table with is_real=True,
    exit_price = event.exit_price, exit_reason = derived
    from trade.close_reason.
    If inning 1 ended with TGT AND trade.close_reason !=
    'EOD' AND still within market hours:
      Start inning 2.

SH4 — Starting a simulated inning:
  _start_inning(prev_inning: Inning):
    entry_price = prev_inning.exit_price
    entry_ts = prev_inning.exit_ts
    direction = prev_inning.direction
    Compute sl_price and tgt_price:
      Read original strategy from state_store via trade_id
      -> signal_id -> scanner_name -> strategy
      Apply strategy.sl_method and tgt_method to new entry_price
      (same rules as real entry price derivation)
    Persist to innings table with is_real=False,
                                 exit_price=None,
                                 exit_reason=None
    Register symbol with live_feed for tick callbacks
    (if not already tracked via other means)
    Add (trade_id, inning_number) to _active_innings dict

SH5 — Tick processing:
  on_tick(tick: dict):
    symbol = tick['symbol']  (or resolve via instrument_cache)
    ltp = tick['last_price']
    For each active inning matching this symbol:
      Check HIT:
        LONG: ltp <= sl_price -> exit reason=SL
        LONG: ltp >= tgt_price -> exit reason=TGT
        SHORT: ltp >= sl_price -> exit reason=SL
        SHORT: ltp <= tgt_price -> exit reason=TGT
      If HIT:
        _close_inning(inning, ltp, exit_reason)

SH6 — EOD handling:
  Subscribe to EodSquareoffComplete event (add to core/events.py
  if not already).
  On EOD: for each active inning:
    _close_inning(inning, current_ltp, "EOD")
  No new innings started after EOD.

SH7 — Closing an inning:
  _close_inning(inning, exit_price, exit_reason):
    Atomic under lock:
      Update innings table: exit_price, exit_ts=now_ist,
                             exit_reason, duration_sec,
                             pnl_pct, pnl_per_share
      Remove from _active_innings
    If alert_per_inning: send telegram INFO with summary
    If exit_reason in ("SL", "TGT") AND inning.inning_number
       < max_innings AND market_windows.is_market_open(now):
      _start_inning(inning)  # start next inning

SH8 — Inning PnL:
  LONG: pnl_per_share = exit_price - entry_price
  SHORT: pnl_per_share = entry_price - exit_price
  pnl_pct = pnl_per_share / entry_price * 100
  For is_real=False innings: pnl is SIMULATED (theoretical).
