DR-U2 — Column layout (per row):

  Identification block (5 cols):
    trade_id
    signal_id
    symbol
    direction
    scanner_name

  INNING 1 block (9 cols, real):
    i1_entry            float
    i1_entry_ts         ISO string
    i1_sl               float
    i1_tgt              float
    i1_exit             float (blank if OPEN)
    i1_exit_ts          ISO string (blank if OPEN)
    i1_exit_reason      "SL" | "TGT" | "EOD" | "OPEN"
    i1_pnl_pct          float (blank if OPEN)
    i1_duration_min     int (blank if OPEN)
    i1_is_real          "REAL" always (inning 1)

  INNING 2 block (9 cols, simulated, may be blank):
    i2_entry, i2_entry_ts, i2_sl, i2_tgt,
    i2_exit, i2_exit_ts, i2_exit_reason,
    i2_pnl_pct, i2_duration_min
    i2_is_real          "SIM" when present, blank otherwise

  INNING 3 block (9 cols, simulated, may be blank):
    i3_entry, i3_entry_ts, i3_sl, i3_tgt,
    i3_exit, i3_exit_ts, i3_exit_reason,
    i3_pnl_pct, i3_duration_min
    i3_is_real          "SIM" when present, blank otherwise

  Aggregate block (4 cols):
    total_innings              int (1, 2, or 3)
    cumulative_simulated_pnl_pct
       sum of i2_pnl_pct + i3_pnl_pct (where present)
    best_inning_pnl_pct
       max of present inning pnl_pcts
    worst_inning_pnl_pct
       min of present inning pnl_pcts

  Total: 5 + 9 + 9 + 9 + 4 = 36 columns per row.

  Empty innings (trade had only 1): i2/i3 columns BLANK
  (not zero, not None — blank string in xlsx, empty cell
  in markdown).

DR-U3 — Data source — new state_store helper:

  Add to core/state_store.py:

    get_inning_summary_by_date(date_iso: str) -> list[dict]

  Implementation: query innings table joined with trades +
  signals to get scanner_name:

    SELECT
      i.trade_id,
      t.signal_id,
      i.symbol,
      i.direction,
      s.scanner_name,
      i.inning_number,
      i.entry_price, i.entry_ts,
      i.sl_price, i.tgt_price,
      i.exit_price, i.exit_ts, i.exit_reason,
      i.pnl_pct, i.duration_sec, i.is_real
    FROM innings i
    JOIN trades t ON i.trade_id = t.trade_id
    JOIN signals s ON t.signal_id = s.signal_id
    WHERE substr(i.entry_ts, 1, 10) = ?
    ORDER BY i.trade_id, i.inning_number

  Returns flat list of per-inning rows. Python code in
  daily_review pivots this into per-trade rows with
  3 inning blocks.

  Add get_innings_summary_by_date tests to test_state_store.
